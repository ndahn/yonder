# Batch Sound Builder

Originally suggested by Shiki, this tool lets you create many [simple sounds](simple_sounds.md) with ease. Each group you setup becomes a new simple sound. 

You can also use the "Groups from Files" button to load a whole folder at once. This will detect sound IDs in filenames (e.g. `c100200300`). Multiple files containing the same sound ID (and different suffixes/prefixes) will be added to the same group/simple sound. This is especially useful when porting sounds from e.g. Dark Souls 3 which generally follow this pattern.
